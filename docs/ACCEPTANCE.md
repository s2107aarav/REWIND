# Verification coverage

Run `npm test` and `npm run test:integration` from a fresh install. The suites contain 17 unit tests and 59 filesystem, service and SIGKILL tests. `tests/lab-recovery.test.ts` adds regressions for advancing fault selection, non-reversible corruption, eligibility exhaustion, reopen/replay evidence and desktop recovery recommendations, including the demo-to-lab-to-restore workflow. The edge-case regressions cover damaged saved evidence, derived catalogs, receipt summaries, demo write boundaries, process locks and path aliases. Tests generate disposable data in the system temporary directory and exercise actual storage bytes.

## Reproducible evidence

- `npm run evaluate` writes dated [summary JSON](../results/summary.json) and [measured report](../results/report.md): 32 physical scenarios, 288 independent oracle comparisons, two captures and independently verified restoration of 10,023 files. Read the actual run's host, cache, timing and denominator fields; two logical roots share one volume.
- `npm run test:ui` writes [UI evidence](../results/ui-smoke.json) and actual screenshots. It creates a three-snapshot demo, injects real lab corruption, inspects the frontier, analyzes recovery options, checks warnings and bounded rows, selects a snapshot, clears the recommendation across scope changes and rejects ungranted paths. Screenshots cover 1440×900 and 800×900.
- `npm run package && npm run test:package` generates an unsigned app and writes [packaging evidence](../results/package-smoke.json). The production core uses the actual packaged native helper to restore and independently verify 97 generated files. This probe is distinct from Electron IPC and native-picker testing.
- `npm run typecheck`, `npm run lint`, `npm run format:check` and `npm run build` cover types, lint, source formatting and production assets. CI config runs core checks on macOS/Linux; external CI execution is not claimed.

## Host limits

Executed evidence is from macOS arm64 with Node 22.23.2. Native macOS publication is tested; Linux implementation is present, but Linux/Windows execution is not claimed. Windows publication fails closed. Packages are unsigned/unnotarized and retain the default Electron icon.

A fresh native-picker test launched the packaged app from outside the source tree, selected a temporary parent through the macOS folder picker, restored 97 files, and independently verified the output using the app’s Verify output control. A separate byte comparison confirmed every restored file matched the generated source. The scripted UI check and the core/helper packaging probe remain separate checks.

Scans describe observation time. Live captures are not atomic application snapshots; malicious ancestor rewriting, encryption, GC, remote backends and repair execution are outside scope. Laboratory mutation and scenario journaling are separate writes; see [durability limits](DURABILITY_AND_LIMITS.md).
